# Datos locales de Music Intelligence v2

Este árbol reserva ubicaciones para datos generados o descargados durante el desarrollo.
Su contenido se mantiene fuera de Git salvo los archivos de estructura.

- `source/`: entradas derivadas del catálogo actual.
- `derived/`: metadatos y representaciones procesadas.
- `embeddings/`: futuros vectores de audio y texto.
- `models/`: futuros pesos o cachés de modelos.
- `cache/`: artefactos temporales regenerables.

No se ha copiado, descargado ni generado ningún artefacto en esta fase.
